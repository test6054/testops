## 0. 用户质疑与裁决

| 质疑 | 裁决 |
|------|------|
| 管理员应有「不同老师档案袋列表」，不是主要靠上方选 | **同意 · B 必做**。主入口升格为 **教师名册列表 → 进入工作台**（现网 `teacher-directory.vue` 已具备列表+跳转） |

| 要不要先「建立」档案袋 | **要 · C 必做**。「启用/建立」语义，无 IDE 式空项目。对齐守卫：模板发布 → 隐私 → 认识档案(onboarding) → 工作台维护 |

## 3. 推荐入口流（产品）

### 3.1 普通教师

```
侧栏「教学档案袋」
  → 模板就绪？否 → 说明等待配置
  → 隐私未签 → 同意（仅本人）
  → 认识档案（可稍后）
  → 我的工作台（待办 + 完整度 + 维护入口）
  → 采集 / 档案分类 / 场景出包 / 看审核进度
```

### 3.2 租户管理员 / 超管（代维护）

```
侧栏「教师名册」（默认着陆推荐）
  → 筛院系 / 完整度 / 关键词
  → 行「进入工作台」
  → 目标教师工作台 + B 钉条「代办：姓名 · 回名册」
  → 采集/维护（审计目标教师）
  → 回名册（清除或保留 teacherId 策略待批改码时定）
```

顶栏 Select：可选保留为 **已进入后的次级切换**，不得替代名册发现。

### 3.3 院系审核

```
侧栏「审核本院材料」→ 审核任务表 → 审这一条
```

需要看完整袋时：从任务钻取到只读档案，或名册「查看档案」，**不是** Segmented「教师办理」。

### 3.4 质量评价（隔离）

```
侧栏「质量评价」→ 专业/方案/学期 → 工作台
未确认方案 → B 钉条，不放大 Empty
```

## 4. 与「建立档案袋」的产品语言

| 勿说 | 应说 |
|------|------|
| 创建工作壳 / 新建 TEACHER 域 | 启用我的教学档案袋 |

## 8. A+B+C 同时成立（产品合同）

| 包 | 谁 | 何时出现 | 主路径 | 禁 |
|----|-----|----------|--------|-----|
| **A** | 普通教师 / 仅本人权限 | 侧栏进档案袋且非管理员选人 | 启用通过后 → **我的工作台**（待办+完整度+维护） | 先选自己；顶栏 Select |
| **B** | `canPickTeachers`（租户管理员/超管等） | 代维护、找人 | **教师名册** → 行「进入工作台」→ 代办钉条 → 回名册 | 顶栏 Select 当唯一发现；未选就大 Empty 英雄区 |
| **C** | 所有教师主体（含被代办的本人首次） | 模板未发布 / 隐私未签 / onboarding 未完成且未 dismiss | 阻断或引导：**启用我的教学档案袋** | IDE「新建空项目」；管理员代签隐私 |

**关系：**

```
          ┌─ C 未完成 ─→ 启用/认识/隐私（可稍后）
进入档案袋 ─┤
          └─ C 完成 ─┬─ 普通人 ─→ A 我的工作台
                     └─ 可选他人 ─→ B 名册（默认）或带 teacherId 深链进入 A 面（代办钉条）
```

**现网锚点：**

| 包 | 已有 | 须补（改码波次 B，另批） |
|----|------|--------------------------|
| A | `teacher-home` · Scope Tag 本人 | 文案「我的工作台」；待办驱动强化 |
| B | `teacher-directory` 行跳 home/archive/intake | 默认着陆/主 CTA「进入工作台」；钉条回名册；弱化顶栏 Select |
| C | readiness 守卫 · privacy · onboarding | 白话「启用」；blocked 态钉条非大卡 |
