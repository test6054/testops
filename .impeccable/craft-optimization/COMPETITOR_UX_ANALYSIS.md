# 竞品 UX 与 mark-vue 差距（联网检索 · 非主题色）

> 结论先讲：你不满意是对的。上一版画廊把「完整优化」窄化成了色板/substrate。  
> 竞品拉开差距的主因是 **工作台形态、给分器交互、任务流、监控面、考后闭环**，不是 Ant 蓝是否换成 Navy。

## 2. mark-vue 相对竞品的真实差距（结构层）

对照 live 壳：`StageWorkbenchShell` / `GradingWorkspaceLayout` / 六程旅程 / SignalBand / 扫描绑定 / 归档卷 / quality / portfolio。

| 维度 | 竞品常态 | mark-vue 现状 | 差距级别 |
|------|----------|---------------|----------|
| **批改心智** | 智学/好分数偏「任务→全屏给分」；Gradescope 偏「按题队列+量表」 | 有沉浸批阅，但量表/给分板/「下一未阅」节奏不如 Gradescope 锋利；工具轨完整度参差 | **P0 产品形态** |
| **给分交互** | 打分板、步长、全对/全错、量表单元格一键 | 依赖现有评分壳；未形成竞品级「给分器产品语言」 | **P0** |
| **进度可见** | 本人进度+他人进度+科组长监控；题纲进度条 | 有批改进度页，但「作战室」感与他人协同弱 | **P1** |
| **异常/质量** | 问题卷、标优/标错、雷同/空白筛 | 绑定异常、复核仲裁有域能力，入口叙事分散 | **P1** |
| **扫描作业** | 扫描中心+异常实时队列 | scanner-kiosk / scan-ops 已强，与教师台视觉/主色不统一 | **P1（系统一致）** |
| **考后闭环** | 学情报告是主价值（雷达/薄弱点/导出） | AI 分析中心+archive 有，但「考完 → 一张行动页」弱于智学叙事 | **P1** |
| **信息架构** | 智学顶栏三域清晰；Gradescope 作业内左侧题纲 | DualDomainSideNav 三域对，考试内旅程与「批改任务中心」双重入口易散 | **P1** |
| **视觉工艺** | 多为清爽运营台；非 Linear 秀场 | Ant 默认皮（上一审查已覆盖） | **P2（附属）** |

**因此选型轴应从「换什么颜色」改为「采用哪套产品形态包」。**

## 3. 完整优化包（穷举形态 · 可多选组合）

见 `ux-morphology-gallery.html`。每包包含：目标角色、对标竞品、必改页面/组件类型、finesse register、与 mark 硬锁冲突点、验收截图面。

## 4. 与 finesse / frontend-design-mark

- finesse：`register=product`，SPECTACLE≤2；用 product-ui（密度、状态全集、workflow shell）与 workflow-ui（提交型控制台），**不用** brand hero。
- mark：壳/DTO/枚举/浅色/≤8px 圆角硬锁；形态优化必须映射到现有 Stage/Grading/Scope 组件，禁止另起营销壳。
