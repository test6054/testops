## 1. 高校实际业务场景（相对 K12）

nybc 面向**高校纸笔考阅 + 质量/档案**，不是智学网那种「周练-错题本-分层作业」日常生态。场景应按角色与时间窗切。

### 1.1 角色 × 时刻 × 决策

| 角色 | 关键时刻 | 要回答的业务问题 | 现网能力落点 |
|------|----------|------------------|--------------|
| **任课 / 主考教师** | 成绩锁定后 24–72h，准备讲评课 | 这班共性弱在哪？先讲哪几题？哪些学生要盯？整卷难不难？ | 教学 Tab：改进建议 / 班级薄弱 / 学情画像 / 整卷 Cronbach·难度·区分度 |
| **命题 / 题组长** | 分析出异常题 / 争议分时 | 哪题区分度异常？错因为何？要不要重判？课程目标有没有映到题？ | 聚类 Tab：错因 / 题目质量 / 映射 / 重判计划 |
| **课程负责人** | 学期末、多场考试后 | 本课目标达成度？多次考试趋势？ | 趋势 Tab：跨考试 / 学期成长 / 目标达成 |
| **院系 / 教务 / 质量岗** | 期中末质量例会、认证材料季 | 校级教学质量/命题/阅卷概览？经验案例是否有效？ | 校级 Tab：校级质量 / 经验有效性 |
| **考试工作台内教师** | 仍停留在「本场」旅程 | 不要被甩进跨考/校级心智 | 锁考入口：应默认本场教学 + 本题治理 |

### 1.2 高校与 K12 的关键差异（选型必看）

| | K12（智学/好分数主战场） | 高校（nybc） |
|--|---------------------------|--------------|
| 主闭环 | 测 → 讲评 → 错题本 → 再练 | 测 → 阅卷质量 → 讲评/补考/成绩发布 →（OBE）目标达成 / 归档 |
| 题的单位 | 知识点细粒度 + 变式练 | 试题 + **课程目标映射** + 重判治理 |
| 测量学 | 有时隐藏在后台 | Cronbach / 区分度是命题质量与认证叙事的一部分 |
| 组织范围 | 班级/年级很强 | 课程 / 院系 / 校级治理与教师本人路径要**隔离** |
| 成功标准 | 「明天课上讲得准」 | 「本场讲清 + 题可治理 + 学期可追溯 + 校级可汇报」 |

据此：**四叶子同权 Tab（教学|趋势|聚类|校级）把四种角色决策揉进一个超市**，不符合高校分工，也加重「多余点击」。

### 1.3 高校考后 5 条旅程（应用来定入口）

```text
J1 讲评准备（本场）     教师 · 考后短时
J2 题目/错因治理（本场） 命题/主考 · 异常触发
J3 课程跨考复盘         课程负责人 · 学期
J4 校级质量例会         教务/质量 · 周期
J5 锁考工作台内复用     同 J1(+J2)，禁止误入 J3/J4
```

与总壳映射：

- **A3**：独立中心承载 J3+J4；考试工作台承载 J1+J2（锁考）；最贴高校。  
- **A2**：一个中心四 Tab = J1–J4 同柜，用户自己换 Tab（可接受，但锁考仍应收敛）。  
- **A1**：J1–J4 一页滚完：学校质量岗偶发可，一线教师准备讲评时噪音过大。

## 2. 业界竞品：考后「分析」形态（不是给分器）

仓库已有阅卷形态对照见 `COMPETITOR_UX_ANALYSIS.md`。本节只收敛 **考后分析 / Insights**。

### 2.1 智学网（K12）——「讲评报告」心智

公开材料与教师实践中的稳定模式：

1. **学情总览**：平均分、等级分布、需关注学生（先宏观）。  
2. **试卷/小题分析**：得分率、困难题标注、选项分布、可下钻到名单与原卷。  
3. **薄弱知识点 / 共性错题**：直接服务「下一节讲什么」。  
4. **导出与再练**：错题集、变式（闭环强于高校产品）。

对 nybc 的启示：

- **Absorb**：本场优先「总览 → 小题/薄弱 → 可执行讲评清单」；同页可滚，关键数字可点。  
- **Reject**：把 K12「错题本/分层作业」硬塞进高校 AI 中心；用系统文案**逼用户点进下一分析类型**。

### 2.2 好分数 / 云批类 ——「统分后报告」

行业常态：统分发布后的班级报告、知识点/难度/区分度表、讲评用题单。信息架构仍是 **本场报告为主**，跨考与校级常在另一管理端。

启示：跨考与校级不要和本场讲评抢同一首屏。

### 2.3 Gradescope Insights（高校）——「命题质量旗标」

官方指南要点（Bubble Sheet / Item Analysis）：

- Statistics：Reliability（Cronbach α）、SEM、标准差等。  
- Item Analysis：选项分布 + Discriminatory score。  
- Insights 面板：自动 **旗标** 低区分度题（如 &lt;0.2），点旗标仍回到题面分析，**不替代整表**。

启示：

- 现网「整卷测量学 + 题目质量（难度-区分度）+ ROI 前置」与 Gradescope **同族**，应作为 **J2 命题治理** 主叙事，而不是与「班级薄弱讲评」平铺成第四装饰 Tab。  
- Insights = 同页上的 flag/AlertStrip，不是「打开题目质量」跳转按钮。

### 2.4 竞品对照矩阵（分析中心专用）

| 维度 | 智学讲评报告 | Gradescope Insights | nybc 现网 AI 中心 | 差距 |
|------|--------------|---------------------|-------------------|------|
| 首问 | 班情总览 | 信度+异常题旗标 | 四 Tab 自选 +「当前视图」元 KPI | P0 IA |
| 本场深度 | 小题得分率→名单→原卷 | Item 表+旗标 | 改进/薄弱/学情/整卷（齐）但同超市 | P1 叙事 |
| 错因 | 知识点/选项错因 | 较弱（量表向） | 错因聚类 + 重判（强于多数竞品） | **差异化资产** |
| OBE/目标 | 弱 | Tag/LO 统计 | 试题-课程目标映射 + 达成度 | **差异化资产** |
| 跨考趋势 | 有阶段对比，常独立模块 | 作业级为主 | 三卡齐但 Filter 爆炸 | P1 |
| 校级 | 管理端另开 | 少 | 校级+经验有效性同 Tab | P1 权限/入口 |
| 系统预判 | 常标困难题/关注生 | 旗标不挡表 | 曾草案主发现 CTA（已否决） | 坚持禁 CTA |

## 3. 映射回 nybc：能力不是缺，是「装错柜子」

现网卡能力其实覆盖高校 J1–J4，问题是 **四叶同权 + 双范围 + 卡内再筛 + 元 KPI**。

| 旅程 | 应默认看到 | 不应默认打扰 |
|------|------------|--------------|
| J1 讲评 | 改进建议、薄弱、学情、整卷三指标 | 校级经验评估、跨考多选考试墙 |
| J2 治理 | Readiness 条、错因、题目质量、映射/重判 | 「当前视图」、第二层六格 Signal |
| J3 趋势 | org 范围 + 三趋势卡；卡工具条保留维度/多选考试 | 再套学年学期 |
| J4 校级 | 权限进入后两块同页 | 与普通教师同权第四 Tab |

**差异化不要丢**：错因聚类、重判、课程目标映射、经验有效性是智学/Gradescope 不完整的部分，CRAFT 应给它们 **清晰入口**，而不是藏在第四个同权 Tab 或 Collapse 超市里示弱。

## 用户纠偏 · 09 带队运营（2026-07-16）

用户否决旧 09 叙事「教师只负责找内容 + 超管 OCR 配置并列」。

### 正模型

| 角色 | 职责 | 界面要交付 |
|------|------|------------|
| **主考 / 科目负责人** | 带一部分教师完成扫描与阅卷 | 进度知况、异常派活/催办、人员负荷、下一拍决策 |
| **协作教师** | 领任务办理（扫/录/评/异常） | 我的待办、本场轻量进度、回交主考 |
| **超管** | 渠道/租户/代理等后台配置 | **不在考试工作台 09 幕** |

### 三程（锁本场）

1. **扫描带队**：应扫/已扫、异常队列、在岗扫描员、派/催

3. **本场学情知况**：讲评优先题、关注学生、题目质量异常（考后分析）

- OCR 渠道/租户策略、代理发布 → 配置域
